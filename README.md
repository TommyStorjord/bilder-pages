# Bilder — app pages

The home page, privacy policy and terms of service for **Bilder**, a private
photo-slideshow application for a Samsung television.

These exist because Google's OAuth consent screen will not leave "Testing"
without them, and "Testing" expires the refresh token every seven days.

This repository is public **only** because the pages have to be reachable. It
holds nothing else: the application itself lives in a private repository, since
that one carries television MAC addresses and a home network's layout.
