Privacy policy

Bilder — last updated 6 November 2026

Bilder is a private application used by a single household. It is not distributed and has no users other than the family that built it. This policy describes exactly what it touches.

What Google account data is accessed

Bilder requests one scope: https://www.googleapis.com/auth/photoslibrary.readonly.appcreateddata.

This grants read-only access to media created by this application. It does not grant access to the rest of a Google Photos library, and Bilder cannot see photographs it did not upload. Within that limit, it reads:

  • album titles and the number of items in each;
  • for each photograph, its description and the temporary URL used to display it.

Bilder never creates, modifies, deletes, shares or uploads anything in Google Photos. The scope it requests does not permit it to.

How that data is used

Solely to display the photographs, with their captions, on a television on the home network. There is no other use.

How it is stored

  • The OAuth refresh token is stored on the television, inside the installed application package, and on the household computer that builds it. It is not transmitted anywhere else.
  • Photographs are not downloaded or kept. They are fetched from Google's own temporary URLs as each one is shown, and those URLs expire by themselves after about an hour.
  • No album or photograph data is written to any disk, database or log.

What is not done

  • No data is shared with, sold to, or transferred to any third party.
  • There is no server, no hosted backend and no account system. The only machines involved are a television, a phone and a computer in one house.
  • There is no analytics, telemetry, advertising or tracking of any kind.
  • No data is used to train any model.
  • No data is retained after the application is uninstalled.

Google API Services User Data Policy

Bilder's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Withdrawing access

Access can be revoked at any time at myaccount.google.com/permissions, which immediately and permanently stops Bilder reading anything. Uninstalling the television application removes the stored token with it.

Contact

Questions about this policy can be sent to the developer contact address listed on the application's Google consent screen.
